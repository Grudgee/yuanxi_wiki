# 知识点摘要

- Cache 写策略影响一致性、延迟和带宽：write through 简化下级一致性但增加写流量，write back 依赖 dirty 位并推迟写回。
- 发生缺失且目标位置含脏数据时，需要先把旧 cache line 写回下级存储，再装入新数据。
- 替换策略决定冲突时牺牲哪个 line；在组相联结构中，替换策略会影响缺失率和控制复杂度。
