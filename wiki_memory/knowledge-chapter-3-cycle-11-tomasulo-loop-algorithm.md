# 知识点摘要

- 动态重命名允许多个循环迭代同时驻留，相当于硬件在不改写代码的情况下动态展开循环。
- issue 时若操作数已就绪写入 `V` 字段，否则记录生产者 `Q` 标签；两个 `Q` 清零后可执行，完成后等待 CDB 广播。
- 基础 Tomasulo 不保留 issue 后的全局程序顺序，因此不能直接提供精确异常；控制分支与 store 次序也需要额外机制。
