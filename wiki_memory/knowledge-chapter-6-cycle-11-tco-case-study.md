# 知识点摘要

- 案例1用TCO模型比较不同服务器成本、功率和性能组合，要求把服务器选择映射到设施可容纳数量、能源费用和整体吞吐。
- 低功耗服务器可能降低电力与基础设施成本，但若性能下降或单机成本上升，单位工作TCO未必改善。
- 简化TCO模型有助于方向判断，但忽略网络、存储、人员、可靠性和负载差异时可能改变结论。

# 关键结论

- 服务器设计决策必须以系统吞吐约束下的总拥有成本比较，而不是只看瓦数或采购价。
- 模型抽象的安全性取决于被忽略成本是否在候选方案间近似不变。
