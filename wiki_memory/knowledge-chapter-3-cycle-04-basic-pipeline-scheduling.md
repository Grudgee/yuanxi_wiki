# 知识点摘要

- 编译器通过保持数据依赖与控制语义不变、重新排列独立指令，使相关指令间隔覆盖功能部件 latency。
- 示例把循环中的整数地址更新移到浮点存储之前，并修正存储偏移，减少 RAW 导致的停顿；调度必须同时保持异常行为与控制路径正确。
- 静态调度依赖目标流水线 latency；处理器实现或 latency 改变时，原调度可能不再最优。
