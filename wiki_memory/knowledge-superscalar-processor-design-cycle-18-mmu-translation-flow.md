# 知识点摘要

- 正常访存时，处理器先把虚拟地址送入 MMU，再由页表项得到物理地址，随后才能继续访问物理内存或 Cache。
- 如果页表项无效或所需页不在内存中，就会触发 Page Fault，处理器必须跳转到异常处理程序，由软件把页面补入并恢复执行。
- 这条路径说明虚拟存储器不仅是地址映射机制，也是一条带异常恢复能力的硬件/软件协同链路。
