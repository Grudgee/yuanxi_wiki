# 知识点摘要

- 超标量的直接动机是提高单线程指令吞吐：不仅提高频率，还要在一个周期内让多条指令进入或完成流水线。
- 标量 RISC 便于流水化，但每周期主要面向一条指令；超标量 RISC 在此基础上复制或扩展取指、译码、发射、执行和写回资源。
- 超标量 CISC 通常不能直接把复杂指令作为统一流水粒度处理，而是在内部转换为更接近 RISC 的微操作，再利用超标量后端执行。
