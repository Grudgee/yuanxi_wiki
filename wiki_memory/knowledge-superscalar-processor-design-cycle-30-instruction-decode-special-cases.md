# 知识点摘要

- 某些 ISA 指令不能像普通指令那样直接解码和下发，需要在解码阶段做特殊识别和转换。
- 分支指令、乘累加/乘法、前/后变址以及 LDM/STM 之类的多寄存器指令，都会给寄存器重命名和后端调度带来额外复杂度。
- 这些特殊情况说明超标量处理器的前端不仅要“识别指令”，还要提前处理语义不规则的指令族。
