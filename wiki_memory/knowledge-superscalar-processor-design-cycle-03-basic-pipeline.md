# 知识点摘要

- 普通处理器流水线把一条指令拆成多个相邻阶段，使不同指令在不同阶段重叠执行。
- 典型教学划分包括取指、译码、执行、访存和写回；每个阶段之间由流水寄存器保存中间状态。
- 流水线提升的是吞吐率而不是单条指令本身的全部延迟；阶段划分是否均衡会影响可达到的频率和利用率。
