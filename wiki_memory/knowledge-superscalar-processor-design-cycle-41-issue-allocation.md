# 本周期总结

- 分配电路负责把新分发的指令写入发射队列空槽，是 Dispatch 与 Issue Queue 之间的入口控制。
- 若采用压缩式队列，可让有效指令集中在队列前部，便于写入和选择；但移动或压缩本身会增加硬件复杂度。
- 若采用非压缩结构，需要扫描空位并选择写入位置；它减少移动，但分配逻辑和空位搜索可能变复杂。
