# 学习范围

本周期完整读取第12章，源文本约28,866字符。Gen3 的目标是以 8.0 GT/s 提高有效吞吐率，同时通过更复杂的均衡和编码模型应对信号完整性问题。与 Gen1/Gen2 的 8b/10b 相比，Gen3 不再按每 8 bit 加 2 bit 控制开销，而以 128 bit 数据加 2 bit 同步头构成 130 bit block，因此编码效率约 98.46%；代价是帧边界、块对齐、扰码和错误恢复规则更加复杂。

## 1. 新模型和块编码（§12.1–§12.2，PDF p.396–417）

Gen3 仍保留 PCIe 的层次和 lane/链路概念，但物理层以 block 为基本传输单位。同步头两位区分 data block 与 ordered-set block，接收端先恢复 130 位边界，再解释块内部内容。块对齐不是任意搜索：训练期间的 EIEOS 提供可识别的边界锚点，随后接收端用同步头持续确认类型。

8.0 GT/s 的编码不再依赖 8b/10b 的 CRD，而采用 128b/130b 的块格式。ordered set 会被组织成 ordered-set block；普通数据流则进入 data block。块之间不能随意插入旧世代控制字符。规范将帧标记 Token 分为 STP、SDP、END、EDB 等用途：STP/SDP 表示包开始，END 表示正常包结束，EDB 表示无效/错误包结束。帧标记放在数据块的固定位置，接收端据此识别 TLP/DLLP 的起止和数据长度。

数据块帧结构要同时支持包连续发送、包跨 block 边界、空闲和部分无效包。发送端必须按规则放置起始标记、结束标记和填充；不能因为一个包恰好在 block 中间结束就破坏下一包的同步头。接收端检查同步头、Token 位置、包边界和长度，遇到帧错误时丢弃当前帧并寻找下一个可恢复边界，而不能把后续字节拼进损坏包。EDB 允许在直通场景标记已无效的包，避免将坏 TLP 继续上交。

## 2. Gen3 发送路径（§12.3，PDF p.418–433）

发送多路复用器在 TLP/DLLP 数据块、有序集和空闲之间选择；当宽链路工作时，byte striping 把字节/块按 lane 分配。x8 示例显示跨 lane 的轮转关系以及接收端必须如何重建；无效 TLP 示例说明交换机直通可能让下游看见一个被中止的包，发送端应使用适当的结束标记而不是伪造完整 TLP。SOS 示例说明 ordered set 的跨 lane 传送与包数据不同，必须保留其结构。

Gen3 的 SOS 规则控制 SKP ordered set 的发送、插入时机和 lane 分布；接收端也有对应规则来识别 SOS、执行时钟补偿并重新建立连续数据流。SKP 不得改变普通包有效载荷，接收端允许按时钟偏差一次增加或删除规定数量的 SKP。

加扰器仍使用 LFSR，但 Gen3 的扰码设计服务于两个目标：随机化数据以降低长串和 EMI，同时增加有利于 CDR 的转换。实现可以每 lane 使用独立 LFSR，也可以使用单个共享 LFSR；两种实现必须产生规范定义的等效序列。LFSR 不是每个 bit 无条件移位，数据 block、ordered set、同步头和 lane 结构决定更新规则。解扰端必须拥有同样的状态推进，不能只按固定字节异或。

Gen3 不允许像 Gen1/Gen2 那样在普通测试中随意关闭扰码：扰码参与时钟恢复，关闭会改变转换密度并使测试不代表正常链路。串行器把 130 位块按 lane 序列化；另一个多路复用器把同步头位与块内容组合到串行输出。

## 3. Gen3 接收路径（§12.4，PDF p.434–445）

差分接收器和 CDR 先恢复比特流。虽然新扰码提高了转换概率，但不能保证任何短区间都有足够跳变，接收端仍需检测失锁。串并转换器用恢复时钟采样各 lane；EIEOS 用于训练时识别 130 位块边界。取得 block alignment 后，前两位同步头决定这是 data block 还是 ordered-set block，后续逻辑才能按相应格式解释。

接收时钟补偿的前提与早期版本相同：链路伙伴时钟存在允许的频率误差。弹性缓冲以恢复时钟写入，以内部时钟读出，并在 SOS 中添加或删除 SKP。接收器不得删除有效数据；若无足够 SKP 或缓冲器接近溢出，属于异常并需触发规范处理。

多 lane 接收需要去偏移。所有 lane 同时出现的 ordered set 提供去偏移机会；实现可用数字缓冲调整各 lane 的读指针。只有完成 lane 对齐，byte un-striping 才能把跨 lane 的数据恢复为原始字节流。解扰器用相同多项式和状态再次异或输入；Gen3 运行下禁用解扰不被允许。

过滤逻辑去掉用于补偿/管理的内容，检查 data block 中 Token 和包边界；Rx Buffer 再把完成的包交给数据链路层。块类型错误、Token 位置错误、包帧错误和 lane 对齐异常都必须阻止坏数据继续上交。第12章还特别指出 128b/130b loopback 的兼容规则：loopback master 可发送真实 ordered set 或 data block，块类型切换时不必要求正常协议里的 SDS/EDS；slave 仍必须允许 SOS 的 SKP 增删，除 SOS/EIEOS 外内容应尽量原样环回，无法取得块对齐时可按需要调整符号继续运行。

## 4. 设计权衡与跨章节连接

128b/130b 大幅降低编码开销，却把更多可靠性职责转移到同步头、Token、LFSR、block alignment 和训练流程。Gen3 不等于“把 8b/10b 换成更宽编码”：它还要求新的帧错误恢复、跨 lane 的块规则和发送均衡。第13章继续讨论 Tx/Rx 电气参数与均衡，第14章说明链路训练如何在 LTSSM 中选择速率并执行 equalization。
