# 知识点摘要

- 这本书把处理器按通用实现路线概括为标量 RISC、超标量 RISC、超标量 CISC 等类型，并明确将超标量 RISC 作为重点对象。
- 超标量处理器的核心目标是让处理器在每个时钟周期尽可能发射或执行多条指令，因此它依赖更深的流水线、更多的并行资源和更复杂的控制逻辑。
- 本书的组织顺序是先讲超标量背景，再依次展开 Cache、虚拟存储器、分支预测、ISA/解码、寄存器重命名、发射与执行、ROB 和异常处理，最后以 Alpha 21264 作为综合案例。
