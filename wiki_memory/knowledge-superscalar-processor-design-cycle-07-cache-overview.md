# 知识点摘要

- Cache 是处理器流水线和较慢下级存储之间的缓冲；超标量处理器每周期可能取多条指令、发多条访存，因而对 Cache 带宽和命中率更敏感。
- I-Cache 直接影响前端能否持续供给足够指令，D-Cache 影响 load/store 延迟和后端发射效率。
- Cache 性能不只由容量决定，还由命中时间、缺失代价、带宽、端口数和层次结构共同决定。
