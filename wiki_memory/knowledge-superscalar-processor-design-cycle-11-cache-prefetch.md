# 知识点摘要

- 预取的目标是在真正使用数据或指令之前，把可能需要的 cache block 提前放入 Cache，从而隐藏下级存储延迟。
- 硬件预取可在 I-Cache 缺失或检测到访问模式时自动取后续 block；软件预取由编译器或程序显式发起。
- 预取必须掌握时机：太晚无法隐藏延迟，太早可能污染 Cache 或替换掉仍有用的数据。

# 适用条件与限制

- 预取对规律访问更有效；对不可预测访问可能带来无效带宽消耗和 Cache 污染。
