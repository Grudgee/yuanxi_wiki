# 知识点摘要

- TLB 的核心作用是缓存最近使用的页表项，把地址转换从“每次查页表”变成“命中时快速给出物理页号”。
- 处理器利用 TLB 降低地址转换的平均延迟，使虚拟地址访问可以更适合流水线和超标量前端的节奏。
- 本周期建立了 TLB 作为 MMU 前置缓存的定位，后续要继续看它如何与 Cache 和异常路径协同。
