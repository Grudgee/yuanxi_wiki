# 本周期总结

- 宽重命名阶段每周期处理多条指令，因此不仅要查询旧 RAT，还要处理同一组指令内部的先后依赖。
- 同一周期中靠后的指令可能依赖靠前指令刚刚产生的新目的寄存器映射，不能只读周期开始时的旧 RAT。
- 解决 RAW 相关时，重命名逻辑必须在同一 bundle 内按程序顺序建立新映射，否则会让后续指令读到错误的物理寄存器。
