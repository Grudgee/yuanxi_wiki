# 知识点摘要

- Load/Store 指令承担访存职责，是超标量后端中最容易受 Cache 和 TLB 影响的一类操作。
- 计算指令包括加减、移位、乘法等不同子类，某些指令如乘累加会带来多个目的寄存器或特殊写回需求。
- 指令类别越多，寄存器重命名和执行单元分配就越复杂。
