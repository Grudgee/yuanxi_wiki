# 知识点摘要

- 指令解码的任务是从指令编码中提取操作码、寄存器号、立即数和控制信息，并驱动后续流水线。
- RISC 指令因长度固定、寻址简单，通常比 CISC 更容易解码；超标量处理器如果每周期解多条指令，就要复制或并行化多套解码逻辑。
- 解码前通常会有指令缓存或缓冲区，用来稳定前端供给并衔接后续译码和重命名阶段。
