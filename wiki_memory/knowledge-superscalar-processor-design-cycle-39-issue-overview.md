# 本周期总结

- 发射阶段从已分发的候选指令中挑选可以执行的指令送入 FU，是乱序执行获得并行度的关键阶段。
- 发射队列保存尚未执行的指令及其源操作数状态；当所有源操作数准备好后，指令进入 ready 状态并向仲裁电路申请。
- 第 8 章把发射过程拆成队列组织、流水线、分配、仲裁和唤醒等子问题。

# 关键细节

- 周期：第 39 个学习周期。
- 源文件：`books/超标量处理器设计.pdf`。
- 范围：第 8 章 §8.1，PDF p.245–249 / 书内 p.233–237 左右。
- 批次规模：估计 6,000–10,000 源字符，低于 80,000 字符监督阈值。

# 来源依据

- 原文说明发射队列、选择电路和唤醒电路共同决定可执行指令如何进入 FU。
