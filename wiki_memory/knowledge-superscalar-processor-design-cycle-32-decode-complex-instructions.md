# 本周期总结

- 乘法/乘累加、前/后变址、LDM/STM 和条件执行都不是普通单结果 ALU 指令，若直接进入宽重命名流水线，会放大寄存器数量、目的寄存器数量和控制条件的不规则性。
- 书中给出两类处理思路：在解码和重命名之间增加缓存吸收膨胀后的微操作，或在解码阶段限制每周期可通过的复杂指令数量。
- 对 ARM 条件执行，CPSR 本身也会成为依赖源；若条件结果尚未确定就盲目重命名，后续指令可能读到错误映射。
