# 学习范围

本周期完整读取第13章，源文本约39,262字符。第13章把前两章的逻辑机制落实为可测试的电气约束：接口必须向后兼容，发送器和接收器必须满足阻抗、共模、电压、抖动和眼图要求，参考时钟可以带扩频，信号补偿则按速率从 Gen1/2 去加重发展到 Gen3 三抽头 Tx equalization 与 Rx equalization。

## 1. 接口、通道与时钟（§13.1–§13.5，PDF p.428–444）

PCIe 组件接口按 lane、差分对和链路宽度组织。实现更宽链路的设备仍需支持 x1；宽链路由多个独立 lane 组成，训练后按 lane 编号和链路宽度工作。电气规范向后兼容：高速端口要能在较低速率下训练和运行，不能假定两端一开始都支持最高速率。

高速串行传输受到插入损耗、反射、串扰、介质频响、连接器和封装影响。单位间隔随速率升高而缩短，同样的边沿失真会占据更大的 UI 比例，因此“额定 GT/s”不等于任意通道上都能达到相同误码率。系统设计要把 Tx、封装、走线、连接器和 Rx 作为一条端到端信道评估。

参考时钟可以采用公共参考或分离参考，接收端从数据恢复时钟。SSC（spread-spectrum clocking）通过缓慢调制参考频率降低 EMI 峰值，调制频率和幅度必须在规范容差内；它不能被误当作随意改变数据速率。2.5、5.0、8.0 GT/s 的参考时钟章节分别说明中心频率、容差及公共时钟/独立时钟场景。链路逻辑必须能在允许的频差下用弹性缓冲吸收速率差。

## 2. Tx 规格与检测（§13.6，PDF p.444–461）

发送器规格包括输出阻抗、差分/共模电压、上升下降时间、抖动、全摆幅和低摆幅模式。差分电压是 D+ 与 D− 的差，单端共模是两条线相对地的共同分量；测试不能只看一条导线的电压。接收器检测电路在复位后确认链路另一端是否存在终端，通过检测状态决定是否进入链路训练。

发送器输出可能使用全摆幅或低摆幅差分电压。较长/高损耗信道更需要全摆幅，短通道可以在功耗和串扰约束下采用低摆幅。直流共模必须处于接收器允许窗口；交流耦合使两端直流工作点可以不同，但发送器、接收器和电容选择必须配套。规范还定义电压 margining：测试时可以在受控范围调整输出以测量裕量，不能把测试调节点当作正常运行保证。

## 3. Rx 规格与信道要求（§13.7，PDF p.461–467）

接收器要满足输入阻抗、共模范围、差分灵敏度、允许的传输损耗和抖动容限。通道传输损耗随频率升高而增大，交流耦合电容隔离直流但会影响低频内容。Rx 测试要用规定的参考点、眼图和压力信号，不能仅以空闲状态波形判断功能。

## 4. 信号补偿（§13.8，PDF p.467–478）

Gen1/Gen2 主要采用去加重（de-emphasis）：连续相同极性的比特受 ISI 影响较大，因此发送器降低重复比特的电压，让转换后的比特保持较好的幅度。2.5 GT/s 与 5.0 GT/s 的固定系数不同；速率提高后 UI 变短、ISI 加重，需要更强或更精细的补偿。去加重不是随意改变所有 bit 的幅度，必须按前后比特历史和规范定义的初始/后续电平工作。

Gen3 使用三抽头 FIR Tx equalizer：pre-cursor、main-cursor、post-cursor 三个系数形成当前输出，支持预加重、去加重和提升等波形整形。系数受到总和、极性、范围及电压限制，预设值提供首次训练的候选起点。预设/比率不是性能保证；接收器会根据当前通道质量提出建议，发送器在 Recovery.Equalization 阶段逐步调整，最终以接收端眼图/误码质量为准。均衡的本质是把频率响应补偿从固定经验值变为链路双方握手。

第13章还介绍 beacon 信号，用于特定低功耗/唤醒场景；它与正常数据眼图不同，接收端要按定义的幅度、持续时间和检测条件识别。信标不是普通包，也不应被交给数据链路层。

## 5. 眼图、抖动与接收均衡（§13.9–§13.12，PDF p.478–480及续页）

眼图把多个 UI 叠加显示，垂直开口反映电压噪声裕量，水平开口反映时间裕量。抖动、随机噪声、确定性噪声、串扰和衰减都会闭合眼图；正常眼图测试应在规定码型、参考点和带宽下进行。压力眼图测试则故意加入受控损伤来测量 Rx 容限：2.5/5.0 GT/s 可在接收器引脚附近评估，8.0 GT/s 由于均衡和通道损耗，测试点与方法更复杂。

Gen3 Rx equalization 包括 CTLE（连续时间线性均衡）等模拟/线性补偿，以及 DFE（决策反馈均衡）等按已判决符号消除后游标干扰的机制。CTLE 可以提升高频成分但也放大噪声；DFE 可补偿特定后游标，却可能受错误传播影响。设计要在眼图开口、误码率、噪声放大、功耗和实现复杂度之间权衡。

## 6. 电源状态与复用结论

第13章末尾的链路状态图说明 L0、L0s、L1、L2、L3 的电气表现逐步降低功耗；L0s/L1 需要重新锁定、训练序列和可能的均衡恢复。电气参数决定逻辑层能否稳定运行：代码、TS1/TS2 和 LTSSM 只是协议表达，最终仍受信道损耗和 Rx 裕量约束。
