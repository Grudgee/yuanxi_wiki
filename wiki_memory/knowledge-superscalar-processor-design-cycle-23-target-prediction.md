# 知识点摘要

- 方向预测只回答“跳不跳”，目标地址预测则回答“跳到哪里”，两者都是前端尽早取指所需的信息。
- 对分支目标的快速预测通常依赖 BTB 或类似缓存结构，把分支 PC 映射到目标地址。
- 没有目标地址预测时，即使方向预测正确，前端也可能因为不知道下一条取指地址而失去周期。
