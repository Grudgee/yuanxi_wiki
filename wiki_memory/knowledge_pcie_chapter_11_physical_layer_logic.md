# 学习范围

本周期完整读取第11章，源文本约31,711字符。第11章限定讨论 Gen1/Gen2 的物理层逻辑；Gen3 的 128b/130b 编码另见第12章。物理层的职责不是解释事务语义，而是把来自数据链路层的 TLP/DLLP/有序集变成可在一条或多条串行通道上传输的符号流，并在接收端恢复、校验、去条带化后交还上层。

## 1. 总体数据路径（§11.1，PDF p.360–372）

发送方向依次经过发送缓冲区、TLP/DLLP/有序集选择与多路复用、宽链路的字节条带化、包格式化、扰码、8b/10b 编码、串行器和差分驱动器。控制逻辑必须在正常包、逻辑空闲、SKP、训练及低功耗相关有序集之间仲裁；上层数据没有可发送时仍不能任意保持直流电平不变。接收方向依次经过差分接收器、接收时钟恢复、解串器、符号锁定、弹性缓冲及时钟补偿、通道去偏移、8b/10b 解码、解扰、字节去条带化、过滤/包对齐和 Rx Buffer。两条方向路径都包含状态和错误检测，因此“物理层只是一根线”是错误模型。

物理层逻辑要同时满足三个约束：保持足够的跳变以便 CDR 锁定；让宽链路各 lane 的数据重新按顺序合并；在速率、时钟和通道延迟不完全相同的现实条件下不损坏符号边界。发送器只允许引入受控的 lane skew，接收器必须通过有序集和缓冲消除剩余 skew。

## 2. Gen1/Gen2 发送细节（§11.2，PDF p.365–387）

发送缓冲区保存待发的 TLP、DLLP 以及物理层有序集。多路复用器/控制逻辑根据 DLLP、链路管理和数据链路层请求选择输出，并在没有包时产生逻辑空闲或规定的控制符号。宽链路先做 byte striping：连续字节按 lane 轮转分配，x1 不需要条带化，x4 以 lane0、lane1、lane2、lane3 的循环方式分发，接收端再逆序合并。条带化不是“复制”数据；每个 lane 只承载自己的符号，任一 lane 的错误、失锁或偏移都会影响完整链路。

包格式规则要求有序集不能被当作普通 TLP 字节切割。x1 示例展示一条 lane 依次传送包符号；x4 示例说明一个 TLP 会跨四条 lane 分散，另一个 TLP 可以在前一包结束后继续；x8 及更宽链路还必须遵守 lane 数和包边界规则。直通交换机可能在包尚未完整到达时开始转发，因此接收端要允许合法的跨 lane、跨包边界场景，同时识别不完整/无效包。

扰码器用于降低长串相同值造成的频谱和时钟恢复问题。扰码按规定的 LFSR 产生序列，与数据符号按位异或；发送和接收端必须以相同初始条件、移位方向和使能规则运行。默认启用，测试/调试可按规范禁用，但禁用会改变信号统计特性，不能当作产品运行模式。扰码不应破坏控制符号语义：控制字符、训练和特殊有序集有规定的处理例外。

8b/10b 将每个 8 位字符映射为 10 位符号，因此原始有效率为 80%，但换取跳变密度、直流平衡、控制字符和错误检测能力。8b/10b 的编码选择依赖当前运行差异（CRD/RD）；一个符号的正/负差异会更新下一符号的选择。差异是 1 和 0 数量的不平衡，CRD 是发送端当前状态的一位记忆。合法代码、控制字符和差异约束共同保证接收器可以检测代码违规或 disparity error。

控制字符包括用于对齐/训练的 K 字符以及电气空闲、退出电气空闲、快速训练、跳过补偿等有序集。TS1/TS2 用于链路初始化和训练；EIOS 在进入低功耗前标记电气空闲；FTS 用于从低功耗唤醒时恢复位锁定；SKP 是 COM 加三个 SKP 符号，用于时钟补偿；EIEOS 用于电气空闲退出并帮助接收端重新建立边界。物理层有序集是管理通道，不是可被上层随意重排的负载。

串行器把每 lane 的并行 10 位符号按规定顺序变为串行比特，差分驱动器把互补的 D+ / D− 波形送入通道。Tx clock 可以来自公共参考或本地参考；发送端要控制 lane-to-lane skew。逻辑空闲必须保持足够跳变，不能简单地无限发送固定 0/1。SKP 的插入要遵守最小间隔、不能插入到不允许打断的序列中等约束，目的是让接收弹性缓冲长期不溢出/欠流。

## 3. Gen1/Gen2 接收细节（§11.3，PDF p.387–394及续页）

差分接收器恢复 D+−D− 的符号电平；CDR 从跳变中恢复 Rx clock。8b/10b 通常提供跳变，但进入 L0s/L1 时可能暂时没有普通数据，于是 FTS/EIEOS 等序列承担重新锁定的任务。失去 bit lock 后接收器必须报告/进入规定恢复路径，而不是把任意比特当成有效 TLP。

解串器按恢复时钟把串行流收集成 10 位符号。符号锁定需要找到合法控制/数据模式和边界；在锁定前输入只是无序 bit（文中用 JABOB 说明这一状态）。本地参考频率与对端存在容差，弹性缓冲把恢复时钟域转换到内部处理时钟域，并通过插入或删除 SKP 符号补偿长期频差。SKP 不能删除普通数据，缓冲器溢出/欠流是物理层严重异常。

宽链路的 lane 到达时间不同，接收器借助所有 lane 同时出现的有序集寻找共同锚点并去偏移。实现可以使用模拟延迟线或数字弹性缓冲；去偏移机会必须在一个明确的、各 lane 同时可识别的模式处执行。去偏移后才可安全做 byte un-striping，否则 lane 顺序正确但字节位置仍错误。

8b/10b 解码器根据首个符号推断极性并处理 lane polarity inversion；随后检查合法代码和当前 CRD 所要求的差异。代码违规是非法 10b 组合，差异错误是符号本身虽像合法码但与当前运行差异不匹配。两类错误都不能静默交给链路层。解扰器使用与发送端相同的多项式/状态恢复原始字节，测试可禁用但要保持双方一致。

过滤和数据包对齐逻辑识别哪些符号属于本物理层、哪些是应丢弃的空闲/补偿符号，并确认 TLP/DLLP 的边界；Rx Buffer 在上交数据链路层之前吸收处理速率差异。若包对齐、lane 去偏移或代码校验失败，物理层错误处理逻辑应阻止坏数据继续传播并按链路层规则产生错误响应。第11章明确把更完整的链路训练放到第14章。

## 4. 错误与电源状态（§11.4–§11.6，PDF p.393–394）

物理层错误包括接收器检测到的代码/差异错误、失去位/符号锁定、lane 对齐失败、缓冲器问题以及不符合格式的有序集。数据链路层看到接收器错误时需要结合 LCRC、序列号和 Ack/Nak 机制处理，物理层不能把错误 TLP 当作正常包确认。

ASPM 相关链路状态包括 L0s、L1、L2、L3：功耗逐步下降，恢复到 L0 的时间逐步增加。L0s 只能硬件控制，L1 可由硬件或软件发起；L0s/L1 在本章被统称为活动状态电源管理。进入低功耗要先发送对应的有序集，退出需要 FTS/EIEOS 和重新锁定。复位后物理层负责初始化链路，但完整 LTSSM 在第14章讨论。

## 可复用结论与边界

* Gen1/Gen2 的 8b/10b 不是单纯编码开销：它同时提供跳变、直流平衡、控制符号和差异/代码错误检测。
* 宽链路正确性链条是“发送条带化 → lane 传输 → 接收去偏移 → 去条带化”；任一步骤都受有序集边界约束。
* SKP 解决时钟频差，FTS/EIEOS 解决低功耗唤醒和锁定，TS1/TS2 解决训练；三者用途不能互换。
* 物理层恢复的是符号与包边界，不负责判断请求是否被目标设备接受；事务错误仍由数据链路层/事务层处理。
