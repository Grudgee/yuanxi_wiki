# 知识点摘要

- 虚拟存储器通过页表把虚拟地址映射到物理地址，使进程看到连续虚拟空间，而物理内存可以离散分配。
- 页表项保存物理页号和状态/权限等信息；虚拟地址页内偏移通常直接保留，与物理页号组合成物理地址。
- Page Fault 表示所需页当前不在物理内存或不可直接访问，需要进入异常处理，由操作系统把页调入或处理错误。
