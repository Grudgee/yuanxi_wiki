# 知识点摘要

- 流水线并不是简单复制阶段即可无限提速，指令之间存在资源竞争、数据相关和控制相关。
- 数据相关使后一条指令需要等待前一条指令产生结果；控制相关使分支结果未确定前的取指路径存在不确定性。
- 超标量设计需要在更宽的流水线中同时处理更多指令，因此相关性检测、旁路和停顿控制会比标量流水线更复杂。
