# 知识点摘要

- 超标量和深流水线会让分支结果在较晚阶段才可见，如果不提前预测，前端就会因等待而停顿。
- 分支预测的目标是在取指阶段尽早猜测控制流方向，使流水线持续向前填充，减少空泡和抹刷流水的代价。
- 第 4 章以分支预测作为核心主题，说明它是超标量前端能否持续供给指令的关键技术。
