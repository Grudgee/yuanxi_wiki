# 本周期总结

- 书中归纳三类重命名实现：扩展体系结构寄存器文件 ARF、使用统一物理寄存器文件 PRF、使用 ROB 实现重命名。
- 使用 ROB 的思路可看作把 ROB 作为 ARF 的扩展，推测结果先停留在 ROB 中，退休时再更新体系结构状态。
- 使用统一 PRF 时，正确状态和推测状态都在同一个物理寄存器池中，依靠映射表和空闲列表管理逻辑寄存器到物理寄存器的对应关系。
