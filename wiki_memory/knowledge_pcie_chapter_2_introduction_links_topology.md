# 知识点摘要

- PCIe 在软件层保持 PCI 的地址空间、配置寄存器和访问方式兼容；物理层改为高速串行、点到点链路。
- 一个 PCIe 通道（Lane）由一对发送差分对和一对接收差分对组成；链路由 1、2、4、8、12、16 或 32 个通道组成，宽度写作 x1–x32。更多通道提高带宽，但增加成本、面积和功耗。
- PCIe 不使用共享公共时钟：时钟嵌入数据流并在接收端恢复；差分信号提升噪声容限并降低电压。事务通过数据包表达，接收端按包边界和模板解析信息。
- Gen1/Gen2 使用 8b/10b，单通道双向聚合带宽分别约 0.5 GB/s 和 1.0 GB/s；Gen3 使用 8 GT/s 与 128b/130b，单通道约 2.0 GB/s，链路总带宽再乘以通道数。
- PCIe 拓扑保持简单树结构。Root Complex 位于根部，Switch 提供扇出和路由，Bridge 连接 PCI/PCI-X 等其他总线，Endpoint 位于树的末端；枚举为软件发现拓扑并分配总线号与资源的过程。

# 关键细节

## 串行传输与带宽

- 并行总线受渡越时间、公共时钟偏斜和多位信号偏斜限制；PCIe 将时钟嵌入数据流，在单通道内每次只传 1 bit，多通道接收端再进行去偏斜。
- 带宽计算：Gen1 = (2.5 Gb/s × 2)/10 = 0.5 GB/s；Gen2 = (5.0 Gb/s × 2)/10 = 1.0 GB/s；Gen3 = (8.0 Gb/s × 2)/8 ≈ 2.0 GB/s。这里按 GB/s 的十进制换算表达书中峰值；128b/130b 的 2/130 开销被近似忽略。
- PLL 依据输入比特流恢复时钟；编码需保持足够的跳变，避免长时间无跳变导致恢复时钟漂移。恢复时钟用于锁存输入，但接收端仍需独立本地时钟以覆盖低功耗或链路无数据状态。

## 链路和拓扑

- 链路必须点到点；Switch 通过多个下行端口构建扇出，按地址或路由信息转发包。Bridge 可向其他 PCIe、PCI 或 PCI-X 总线提供接口，前向桥支持旧卡接入新系统，反向桥支持新卡接入旧系统。
- Endpoint 不是 Switch 或 Bridge，通常只有一个上行端口并位于树的末端；原生 PCIe Endpoint 面向 PCIe 设计，通常为内存映射设备；Legacy Endpoint 可保留 I/O 事务和锁定请求等兼容特性。
- RC 是 CPU/DRAM 子系统与 PCIe 树的接口集合，规范给出必需和可选能力，而不限定内部芯片划分。软件通常把 RC 内部结构看作 PCI 总线 0，把 RC 端口和 Switch 内部结构抽象为桥，以复用 PCI 的路由和枚举方法。
- PCIe 软件枚举发现拓扑、分配总线号和系统资源；硬件内部实现可以是供应商自定义的，不必真的存在软件所看到的内部 PCI 总线。

- 本文件覆盖第2章的体系结构导论，不替代后续章节对 TLP、DLLP、配置寄存器、流量控制和物理层状态机的规范化说明。
