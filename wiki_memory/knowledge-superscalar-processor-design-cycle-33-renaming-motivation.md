# 本周期总结

- 第 7 章把相关性分为寄存器数据相关、存储器数据相关、控制相关和结构相关。
- 在寄存器数据相关中，RAW 是真正的数据依赖，WAW 和 WAR 属于名字相关，可通过给不同写入分配不同物理寄存器来消除。
- 寄存器重命名的核心价值是扩大乱序执行空间：消除假相关后，后端可以更自由地调度指令。

# 关键细节

- 周期：第 33 个学习周期。
- 源文件：`books/超标量处理器设计.pdf`。
- 范围：第 7 章 §7.1，PDF p.206–209 / 书内 p.194–197 左右。
- 批次规模：估计 6,000–10,000 源字符，低于 80,000 字符监督阈值。

# 来源依据

- 原文在 §7.1 明确列出 WAW、WAR、RAW，并指出只有 RAW 是真正相关，另外两类可通过不同寄存器名字解决。
