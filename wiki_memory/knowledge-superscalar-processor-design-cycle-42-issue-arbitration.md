# 本周期总结

- 仲裁电路在多条 ready 指令之间选择哪些指令进入 FU；规则可能考虑年龄、功能部件类型和端口资源。
- 每个 FU 或每类 FU 可以有独立仲裁器；拆分队列能降低单个仲裁器容量和延迟，但会引入跨队列平衡问题。
- 仲裁的结果不仅决定本周期执行哪条指令，也会触发目的寄存器 tag 广播，影响后续指令唤醒。
