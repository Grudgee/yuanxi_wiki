# 知识点摘要

- 云计算把WSC能力包装为按需租用的计算、存储和网络资源，用户无需提前建设峰值容量，提供商通过多租户与规模采购摊薄成本。
- Utility computing的关键属性包括快速配置、按使用量计费、成本可组合性、弹性扩缩和将容量风险转移给提供商。
- 云服务可降低初创和波动型业务的进入门槛，但用户仍需处理可用性SLA、数据迁移、供应商依赖、隐私和带宽成本。

# 关键结论

- 云计算的经济优势不仅来自硬件价格，还来自供应链、运营自动化、统计复用和容量风险的重新分配。
- 按需价格为性能/成本研究提供了可观察指标，但历史云价格不能直接代表当前市场。
