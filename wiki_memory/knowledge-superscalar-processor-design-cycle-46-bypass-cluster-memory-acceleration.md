# 本周期总结

- 旁路网络允许执行结果不必先写回寄存器文件再被下一条指令读取，从而缩短相关指令之间的等待时间。
- 操作数选择要在寄存器文件读出值、旁路值和可能的推测值之间选出正确来源，直接影响执行级关键路径。
- Cluster 结构通过把执行资源和旁路网络分组来控制复杂度，但跨 cluster 通信会带来额外延迟；存储器指令加速则继续处理 load/store 不确定 latency。
