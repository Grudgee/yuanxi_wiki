# 知识点摘要

- 分支指令重新连接到第 4 章的控制流主题，在 ISA 级别定义了控制转移的基本形式。
- 杂项指令和系统相关指令常带有特殊语义，可能不能像普通 ALU 指令一样直接进入同一执行路径。
- 异常会打断流水线并要求处理器清空错误路径；在超标量/乱序环境中，异常处理比简单顺序流水更复杂。
