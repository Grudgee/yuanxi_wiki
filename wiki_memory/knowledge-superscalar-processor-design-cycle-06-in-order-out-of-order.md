# 知识点摘要

- 乱序执行允许指令在处理器内部不按程序顺序完成，但处理器对外必须呈现按程序顺序更新的结果。
- ROB 用于暂存已执行完成但尚未提交的结果；只有当最旧指令结果有效且无异常或误预测时，才可退休并更新体系结构状态。
- 这种“乱序执行、按序退休”的框架让处理器在隐藏延迟的同时维持精确异常和可恢复状态。
