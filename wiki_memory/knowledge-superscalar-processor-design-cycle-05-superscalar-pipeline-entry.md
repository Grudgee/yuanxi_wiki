# 知识点摘要

- 超标量流水线要求前端每周期提供多条指令，后端也需要足够执行资源，否则宽取指无法转化为有效吞吐。
- 本书将超标量流水线进一步分成顺序执行和乱序执行两类；两者都要保持程序最终可观察状态与程序顺序一致。
- 顺序执行实现较简单，但遇到长延迟或相关指令时容易阻塞；乱序执行可绕过暂时不能执行的指令，提高功能部件利用率。
