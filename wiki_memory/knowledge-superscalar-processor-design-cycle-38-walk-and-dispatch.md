# 本周期总结

- WALK 利用 ROB 中保存的旧映射信息，从最新指令向前逐条撤销错误路径对 RAT 的修改，硬件成本较低但恢复慢。
- 当发现分支预测失败或异常时，WALK 需要暂停流水线，并把 RAT 倒回到正确路径所需的状态。
- 第 7 章末尾转入 Dispatch：重命名后的指令要写入 ROB、发射队列等结构，正式进入后端调度域。

# 关键细节

- 周期：第 38 个学习周期。
- 源文件：`books/超标量处理器设计.pdf`。
- 范围：第 7 章 §7.5.2–§7.6，PDF p.237–245 / 书内 p.225–233 左右。
- 批次规模：估计 10,000–16,000 源字符，低于 80,000 字符监督阈值。

# 来源依据

- 原文说明 WALK 从 ROB 底端逐条写回先前映射，并在 RAT 恢复后从正确地址继续取指；随后进入“分发”。
