# 知识点摘要

- Cache 通常由 tag、data、valid 和 dirty 等状态组成；地址被拆分为索引、tag 和块内偏移。
- Direct mapped 结构简单快速，但冲突缺失较高；组相联结构通过多个 way 降低冲突，但增加 tag 比较和选择逻辑。
- 超标量访问压力会放大 Cache 端口、带宽和冲突问题，因为同一周期可能有多个取指或访存请求竞争同一结构。
