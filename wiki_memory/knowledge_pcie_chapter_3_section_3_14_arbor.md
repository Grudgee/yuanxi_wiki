# 知识点摘要

- MindShare Arbor 用于读取或写入 memory、IO、配置空间地址，并以解码、可读的形式展示结果。
- 工具可扫描系统中所有 PCI 可见 Function 的配置空间，解释 PCI/PCI-X/PCIe 标准结构，也可解码部分 x86 结构和设备特定寄存器。
- 用户可用 XML 创建自定义译码文件，覆盖配置空间、memory 空间和 IO 空间结构；扫描结果可保存为开放 XML 格式并在其他系统查看。

# 关键细节

- 本书没有把全部配置寄存器集中放在一个专章，而是按相关主题分散到全书；Arbor 被建议作为配置寄存器空间的辅助学习工具。
- 功能清单还包括直接访问任意 memory/IO 地址、写入任意配置空间位置、查看已解码的标准或非标准结构，以及持续增加的新结构支持。
- Arbor 的寄存器/字段定义随 PCIe 协议版本更新；工具的实际支持范围应以所安装版本为准。
