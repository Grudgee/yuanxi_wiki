# 知识点摘要

- AMD Opteron 的双端口 D Cache 示例说明真实处理器会在面积、端口、bank 冲突和访问延迟之间折中。
- 多端口并不保证所有访问都并行完成；如果多个端口访问映射到同一 bank，仍可能发生结构冲突。
- 超标量取指要求 I-Cache 每周期提供足够多的指令，若 fetch group 跨 cache line 或遇到分支，前端供给能力会下降。
