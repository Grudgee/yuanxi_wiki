# 本周期总结

- 发射逻辑自身也会成为关键路径，因此需要将唤醒、选择、读寄存器和执行入口等动作分阶段组织。
- 发射流水线越深，频率更容易提高，但唤醒和选择之间的延迟也可能增加，影响背靠背依赖指令的执行效率。
- 对超标量处理器来说，发射流水线必须在周期时间和依赖传播速度之间折中。
