# 知识点摘要

- 指令集体系直接影响解码复杂度、流水线设计和超标量实现成本。
- RISC 通常以固定长度指令、较简单寻址和较清晰的流水线控制为特征，更适合做高频和宽发射实现。
- CISC 通过更复杂的编码和寻址表达更多操作，但在超标量实现中通常需要更复杂的内部拆解与控制。
