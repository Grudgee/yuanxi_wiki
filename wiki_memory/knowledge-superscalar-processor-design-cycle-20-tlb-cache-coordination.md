# 知识点摘要

- 当 TLB、Cache 和页表状态位一起进入流水线后，地址访问同时受到翻译延迟、命中时间和属性检查的影响。
- Cache 中的数据可能比物理内存更“新”，但页表状态位由 OS 读取前需要确保写回完成，否则会看见过期的 dirty/use 状态。
- 这部分把虚拟存储器从“地址转换”扩展为“带缓存、带状态更新的流水线子系统”。
