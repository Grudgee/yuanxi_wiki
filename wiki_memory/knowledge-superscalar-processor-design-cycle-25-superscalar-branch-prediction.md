# 知识点摘要

- 超标量前端需要同时处理方向预测、目标地址预测和错误恢复，因此分支预测不再是单一模块，而是一组协同子系统。
- 预测效果直接决定指令供给是否足够连续；在高发射宽度处理器里，预测失误的吞吐损失会被放大。
- 本周期把前面的方向预测、目标预测和恢复机制收束到超标量设计语境中。
