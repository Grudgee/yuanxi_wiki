# 知识点摘要

- 分支方向预测的目标是判断分支会 taken 还是 not taken，以便提前决定取指路径。
- 方向预测器的设计要在准确率、硬件开销和训练速度之间折中；更复杂的历史相关机制通常能提升命中率，但面积和控制逻辑也更高。
- 对超标量前端来说，方向预测准确与否直接影响取指带宽是否能持续喂饱后端。
