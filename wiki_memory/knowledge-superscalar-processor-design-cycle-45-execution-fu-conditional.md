# 本周期总结

- 第 9 章进入执行阶段，首先讨论 FU 类型，包括 ALU 等基础运算单元以及不同操作的执行延迟差异。
- ARM 条件执行在超标量处理器中会继续带来后端复杂度：条件尚未确定时，重命名和执行路径可能产生错误映射或无效操作。
- 一种处理方向是插入 select uOP 之类的内部选择操作，让硬件在条件确定后选择正确结果，但这会约束指令组织并增加硬件/工具链复杂度。
