# 知识点摘要

- loop unrolling 复制循环体以减少分支/地址更新开销，并让编译器看到不同迭代间可并行的操作。
- 展开后必须用不同寄存器承载不同迭代的临时值，消除 name dependence；随后跨迭代调度才能隐藏 load-to-use 和 FP latency。
- 展开收益受代码膨胀、寄存器压力、余数迭代处理以及真实数据依赖限制。

# 适用条件与例外

- 只有不同迭代不存在阻止重排的真实依赖或内存别名时，才能获得跨迭代 ILP。
- 非整除的迭代次数需要清理循环或其他边界处理。
