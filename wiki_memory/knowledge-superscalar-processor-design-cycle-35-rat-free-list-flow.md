# 本周期总结

- RAT 保存逻辑寄存器到当前物理寄存器的映射；源寄存器重命名时查 RAT，目的寄存器重命名时从 Free List 申请新的物理寄存器。
- Free List 可用 FIFO 等结构保存空闲物理寄存器编号；目的寄存器占用新物理寄存器后，RAT 立刻更新为新映射。
- 对外可见的体系结构状态只应来自已退休指令；推测状态虽然在 PRF/ROB 中存在，但不能被外部当作已提交结果。

- 批次规模：估计 6,000–10,000 源字符，低于 80,000 字符监督阈值。

# 来源依据

- 原文说明源寄存器查 mapping table/RAT，目的寄存器从空闲列表取得物理寄存器，并将新关系写回 RAT。
