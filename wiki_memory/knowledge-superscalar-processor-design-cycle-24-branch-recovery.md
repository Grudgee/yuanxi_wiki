# 知识点摘要

- 分支预测失败会导致前端沿错误路径取入的指令必须被抹掉并重新取指，这是超标量和深流水线中最常见的性能损耗来源之一。
- 恢复机制的目标是把处理器状态拉回到正确分支结果之后的状态，并尽可能快速地重新开始正确路径取指。
- 由于流水线更深、并行度更高，错误恢复的代价也会更大，因此恢复路径必须与预测机制一起设计。
