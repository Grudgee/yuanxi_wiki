# 知识点摘要

- 仅按单个分支地址维护局部 2-bit 状态无法利用分支间相关性；correlating predictor 把最近若干分支的全局历史加入索引。
- `(m,n)` 预测器使用最近 `m` 个分支结果选择预测集合，每个分支在所选集合中由 `n` 位计数器预测；增加历史可区分同一分支在不同路径上下文中的行为。
- 预测器应按相近硬件预算比较，因为更多历史和更多表项都会增加容量与访问复杂度。

- 全局历史会受无关分支干扰；表项共享还会产生 aliasing。
