# 知识点摘要

- SMT把动态调度窗口中的多个线程指令共同参与发射选择，并共享核心资源。
- SMT收益来自更高资源利用率，但线程会竞争缓存、队列、寄存器和带宽，因此线程数增加不保证线性加速。
