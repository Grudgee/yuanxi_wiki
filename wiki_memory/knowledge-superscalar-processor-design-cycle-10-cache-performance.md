# 知识点摘要

- 写缓存可以把脏行写回从关键访问路径中分离出来，降低缺失处理时串行等待下级存储的影响。
- Cache 访问可被流水化，提高吞吐但可能增加单次访问延迟；这对超标量处理器的持续供给尤其重要。
- 多级 Cache 通过小而快的 L1 与较大 L2/L3 折中命中时间和缺失代价；Victim Cache 可减少冲突缺失。
