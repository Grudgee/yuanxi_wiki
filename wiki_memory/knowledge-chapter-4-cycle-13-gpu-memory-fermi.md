# 知识点摘要

- GPU地址空间在共享范围、容量、延迟和缓存方式上不同，Fermi加入缓存、ECC和更强原子操作。
- 合并访问和局部共享存储可降低全局带宽压力，但GPU缓存一致性和虚拟内存语义不能按CPU默认假设。
